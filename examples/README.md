# examples —— 动手实践目录

> 配套教学案例 [`docs/从零看懂-db-mcp.md`](../docs/从零看懂-db-mcp.md) 第 9 站使用。
> 这里不是"示例代码欣赏"，而是**能真实跑起来、亲手验证**的练习。

## 一句话

`practice.mjs` 会**自动启动本项目**，然后假装自己是 AI 客户端，通过 stdio（对讲机）和它对话，一步步带你走完"握手 → 列工具 → 建表 → 插入 → 查询 → 看表结构 → 读配置"的完整流程，并把每一步收发的原始 JSON 都打印出来。

## 前置条件

- **Node.js 22 或更高版本**（本项目用到了 Node 22 内置的 `node:sqlite`）。
- 在项目根目录（`db-mcp/`）打开终端。
- 不需要装任何数据库服务——SQLite 的数据就是一个本地文件。

检查版本：

```bash
node -v     # 应显示 v22.x 或更高
```

## 怎么跑

在项目根目录：

```bash
node examples/practice.mjs            # 推荐：显示底层协议细节（教学用）
node examples/practice.mjs --quiet    # 只看每一步的结果，不打印原始 JSON
```

## 你会看到什么

- 服务启动日志（配置来源、SQLite 实验特性警告——**警告无害，可忽略**）。
- 9 个带编号的步骤，每步都有"💡 人话解释"。
- 默认模式下，每步还会打印 `[对讲机·发出]` / `[对讲机·收到]` 的原始 JSON，让你看清 AI 和服务器到底"说了啥"。

真实查询的结果长这样（注意 `rows / fields / rowCount` 的统一结构）：

```json
{
  "rows": [
    { "id": 1, "name": "小明", "score": 90 },
    { "id": 2, "name": "小红", "score": 95 }
  ],
  "fields": [{ "name": "id" }, { "name": "name" }, { "name": "score" }],
  "rowCount": 2
}
```

## 关于 `demo.db`

- 运行脚本会真实生成 `examples/demo.db`，里面有一张 `student` 表和小明、小红两行数据。
- 这是**练习产物**，可以随时删除；每次运行都会先清空再插入，所以结果稳定一致。
- 想亲眼确认数据真的落地了？用任意 SQLite 工具打开它，执行 `SELECT * FROM student`。

## 自己改着玩

1. 打开 `practice.mjs`，找到第 2~4 步的 `sql`，把 `student` 换成你自己的表名、字段。
2. 在第 4 步的查询里加个 `WHERE score > 90`，看看返回的变化。
3. 把 `--quiet` 去掉，对比两种模式下对协议细节的理解。

## 常见问题

| 现象 | 原因 / 处理 |
|------|------------|
| 报 `node:sqlite` 相关错误 | Node 版本太低，需要 22+ |
| 看到 `ExperimentalWarning: SQLite` | 无害，忽略即可 |
| 卡住不动 | 脚本内置 8 秒请求超时，会打印错误并退出；检查服务是否被安全软件拦截 |
| 想换数据库类型 | 把脚本里的 `CONN` 换成别的连接串（如 `duckdb:` 文件），但对应的驱动需已在 `node_modules` |
